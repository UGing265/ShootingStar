# Taste

## Workflow

- Prefers implementation work left uncommitted — asks the agent explicitly not to commit, so commits/reviews stay under the user's control. Confidence: 0.6

## Communication

- Wants acceptance/verification commands' raw output reported verbatim, not just a summarized claim of success. Confidence: 0.55
- Rejects em/en dashes in copy and UI text; written output should use plain punctuation instead. Confidence: 0.65
- Expects cited references in docs to be factually exact (verifies paper titles and source links, corrects wrong ones). Confidence: 0.5
- Wants each task completion to end with an explicit "Status:" line summarizing what was done and the evidence. Confidence: 0.6
