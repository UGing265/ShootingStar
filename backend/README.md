# ShootingStar — Backend Service

Python backend service for market data ingestion, snapshot management, walk-forward ML experiment execution, pattern recognition, and FastAPI REST endpoints.

## Structure
- `shootingstar/`: Python package modules (application, domain, adapters, api, cli).
- `alembic/` & `alembic.ini`: Database migrations.
- `tests/`: Automated pytest test suite.
- `pyproject.toml`: Backend project configuration and dependencies.
